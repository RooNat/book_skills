# 先调整再翻转, 再谈放弃

## R — 原文 (Reading)

> 10次小微调好过一次痛苦的关键转型。
>
> — Alberto Savoia, 第7章「微调远胜关键转型」

---

## I — 方法论骨架 (Interpretation)

坏数据不是只能导向两个极端: 硬扛或放弃。
预型的价值在于便宜地学习市场到底对什么有反应。
第一版创意可能是错误的它, 但附近可能存在更正确的版本。
因此, 先用 YODA 指引小调整: 改价格、人群、场景、包装、交付方式、承诺或使用频率。
如果多次小调仍无信号, 再翻转关键假说。
如果翻转后仍无强 YODA, 才考虑放弃。
这让团队在低成本阶段吸收坏消息, 避免后期痛苦 pivot。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: BusU
- **问题**: 初始通勤巴士课程创意并非一开始就等于最终商业模型。
- **方法论的使用**: 作者根据多轮 YODA 调整目标人群、课程形式、价格和交付。
- **结论**: 市场反馈不是判死刑, 而是指向更好版本。
- **结果**: BusU 从初始创意演化出更清晰的可行模型。

### 案例 2: 达雷尔的尿布服务
- **问题**: 创意可能有市场, 但未必适合创始人自己。
- **方法论的使用**: 作者提醒验证市场正确后, 还要判断是否适合自己和世界。
- **结论**: 有些创意应调整目标或放弃, 即使它看似能赚钱。
- **结果**: 创业选择被纳入边界判断。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 早期预型数据低于预期, 用户想知道是否放弃。
2. 用户想 pivot, 但还没有做过小幅调整。
3. 用户发现部分用户有兴趣, 但行为和原假说不一致。
4. 用户需要从坏数据里提取下一轮试验方向。

### 语言信号

- “数据不好, 是不是该放弃?”
- “要不要 pivot?”
- “用户没按我们预期行动”
- “怎么根据试验结果调整产品?”

### 与相邻 skill 的区分

- 与 `tri-meter` 的区别: TRI 判断证据方向; 本 skill 根据证据设计调整路径。
- 与 `right-it-diagnosis` 的区别: 诊断 skill 判断失败类型; 本 skill 在前提风险下探索附近机会。

## E — 可执行步骤 (Execution)

1. **复述坏数据**
   - 完成标准: 写出原 xyz、实际结果和差距。

2. **提取市场学习**
   - 完成标准: 找出用户对哪一部分有反应、无反应或意外反应。

3. **列出小微调**
   - 完成标准: 至少提出 3 个低成本调整, 分别涉及价格、人群、场景、承诺或交付。

4. **决定调整/翻转/放弃**
   - 完成标准: 若仍有局部强信号, 先调整; 若核心假说反复失败, 翻转; 若伦理/适配/多轮 YODA 都不支持, 放弃。

5. **设计下一轮测试**
   - 完成标准: 为选定调整写出新的 xyz 或预型方向。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 创意明显违法、伤害大于收益或违反用户安全, 不应通过调整继续推进。
- 数据只有意见没有行为, 应先调用 `escape-thoughtland`。
- 只有一次极弱样本, 不足以判断调整方向, 应先补试验。

### 作者在书中警告的失败模式

- 被首次糟糕 YODA 过早打击。
- 在空想之地微调创意, 而不是用 YODA 指引。
- 把关键转型拖到重投入之后才发生。

### 作者的盲点 / 时代局限

- 连续微调也可能变成拖延放弃; 高机会成本场景需要设定试验上限。
- 有市场需求不代表创意适合团队能力、价值观或社会影响。

### 容易混淆的邻近方法论

- `tri-meter`: 先判断多轮证据是否足够。
- `market-failure-prior`: 评估新创意初始风险。
