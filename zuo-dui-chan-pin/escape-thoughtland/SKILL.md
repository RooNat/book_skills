# 逃离空想之地证据

## R — 原文 (Reading)

> 你只能通过在真实世界中进行试验来把它发掘出来。
>
> — Alberto Savoia, 第2章「空想之地」

---

## I — 方法论骨架 (Interpretation)

空想之地是创意被意见、想象、焦点小组、专家判断和二手数据包围的地方。
这些东西可以启发思考, 但不能证明市场会行动。
意见容易制造假阳性: 大家说喜欢, 上市没人买。
意见也会制造假阴性: 大家说不行, 真实市场后来热烈响应。
OPD 虽然是数据, 但来自别人、别的时间、别的市场和别的目的, 不能替代当前创意的一手证据。
逃离空想之地的动作是把“他们怎么说”改成“他们愿意付出什么”。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: LadyLike 啤酒
- **问题**: 焦点组里女性用户很喜欢窄瓶装清淡风味啤酒。
- **方法论的使用**: 作者指出这类调研没有让用户付出购买代价。
- **结论**: 焦点组热情可能是假阳性。
- **结果**: 上市后购买和复购很少。

### 案例 2: 作者加入谷歌
- **问题**: 作者身边很多聪明人认为搜索市场已饱和, 广告没人点。
- **方法论的使用**: 作者没有把负面意见当作决定性证据。
- **结论**: 意见也会制造假阴性。
- **结果**: 谷歌搜索和广告后来成为巨大成功。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户拿焦点小组、访谈、问卷或专家背书证明创意可行。
2. 用户引用竞品、行业报告或历史案例, 但没有自己的目标市场数据。
3. 用户被负面意见劝退, 但没有做真实市场测试。
4. 用户把点赞、评论、浏览量当作购买意图。

### 语言信号

- “用户都说喜欢”
- “调研报告显示这个市场很大”
- “竞品成功说明我们也能做”
- “专家说这个方向不行”

### 与相邻 skill 的区分

- 与 `xyz-hypothesis` 的区别: 本 skill 先判断证据是否可靠; `xyz-hypothesis` 把模糊假说改写为可测试形式。
- 与 `skin-in-game-caliper` 的区别: 本 skill 区分意见/OPD/YODA; `skin-in-game-caliper` 进一步给行为证据分强弱。

## E — 可执行步骤 (Execution)

1. **盘点当前证据**
   - 完成标准: 把用户提供的证据标记为意见、OPD、弱行为数据或 YODA。

2. **识别假阳性/假阴性风险**
   - 完成标准: 说明每条证据为什么可能误导, 特别是没有切身利益或目标市场不匹配之处。

3. **改写为 YODA 需求**
   - 完成标准: 为每个关键判断提出一个能由当前目标市场亲自验证的行为证据。

4. **建议下一步工具**
   - 完成标准: 若假说模糊, 转 `xyz-hypothesis`; 若需要试验, 转 `pretotype-yoda`; 若已有行为数据, 转 `skin-in-game-caliper`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已经提供真实购买、留存、复购、预订或付费试验数据。
- 用户只是需要整理访谈洞察, 不需要判断产品是否值得做。
- 用户的问题是如何设计具体试验, 应直接调用 `pretotype-yoda`。

### 作者在书中警告的失败模式

- 在空想之地长期逗留。
- 焦点组假阳性。
- 翻译缺失导致创意被误判。
- 依赖 OPD 捷径。

### 作者的盲点 / 时代局限

- 某些早期研究型产品很难立即取得付费行为, 但仍可寻找时间、数据、试用承诺等替代切身利益。
- 严格合规场景中, 真实行为测试需要额外审查。

### 容易混淆的邻近方法论

- `market-engagement-hypothesis`: 用于明确市场会怎么参与。
- `skin-in-game-caliper`: 用于衡量证据强度。
