# 用 TRI 计量仪综合多次试验

## R — 原文 (Reading)

> TRI计量仪：这是一个工具，用于映射出并可视化地呈现出预型试验的结果。
>
> — Alberto Savoia, 第6章「TRI计量仪」

---

## I — 方法论骨架 (Interpretation)

TRI 计量仪把试验结果从零散数字变成方向判断。
每次预型都是一支箭, 指向“非常不可能”到“非常有可能”的某个位置。
市场失败律像一支默认向下的大箭头, 提醒你少量好结果不足以证明成功。
因此, 不要基于一次试验下重注。
把多轮 YODA 与各自 xyz 假说对照, 看证据是否稳定、是否增强、是否来自更强切身利益。
最后输出不是“保证成功”, 而是争取、调整或放弃的风险判断。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 隔日寿司
- **问题**: 单次改标签试验得到购买数据, 但还不足以决定全面投入。
- **方法论的使用**: 作者把结果映射到 TRI, 并提醒需要更多箭头。
- **结论**: 多轮试验才能抵消市场失败律。
- **结果**: TRI 成为解释 YODA 的可视化工具。

### 案例 2: BusU
- **问题**: 通勤巴士课程经历多轮假说、预售和课程试验。
- **方法论的使用**: 作者把多组 YODA 用来更新商业模型。
- **结论**: 证据支持从初始创意调整到更可行模型。
- **结果**: 团队得到比一次试验更稳的决策基础。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户做了预售、假门、试用或线下测试, 需要判断结果。
2. 用户想知道一次好结果是否足以加大投入。
3. 用户有多轮数据但不知道如何汇总。
4. 用户要决定争取、调整还是放弃。

### 语言信号

- “这些试验结果够不够?”
- “能不能基于这次预售继续做?”
- “我们做了几轮测试, 该怎么判断?”
- “现在应该继续、调整还是放弃?”

### 与相邻 skill 的区分

- 与 `skin-in-game-caliper` 的区别: 卡尺评估单个证据强度; TRI 综合多轮证据方向。
- 与 `adjust-before-pivot` 的区别: TRI 先判断证据位置; adjust skill 负责坏数据后的改法。

---

## E — 可执行步骤 (Execution)

1. **整理每轮试验**
   - 完成标准: 每轮都有 xyz、样本、行为结果、切身利益强度和异常说明。

2. **逐轮映射 TRI**
   - 完成标准: 标注每轮结果指向非常不可能/不可能/不确定/可能/非常可能之一。

3. **检查箭头数量和质量**
   - 完成标准: 说明是否只有一次试验, 是否样本重复, 是否切身利益足够强。

4. **输出决策**
   - 完成标准: 给出争取、调整或放弃, 并说明还缺哪类箭头。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 还没有真实市场行为数据。
- 数据只是浏览、点赞或意见, 应先调用 `skin-in-game-caliper`。
- 用户需要设计下一轮试验, 而不是综合现有试验。

### 作者在书中警告的失败模式

- 一次试验就下重注。
- 对模糊或损坏数据强行解释。
- 证实性偏差扭曲试验和结论。

### 作者的盲点 / 时代局限

- TRI 是决策辅助, 不是严格统计模型; 高风险投资仍需要更正式的统计和财务分析。
- 长期留存、复购、渠道经济性可能需要比预型更长的数据窗口。

### 容易混淆的邻近方法论

- `adjust-before-pivot`: 用于 TRI 指向不佳后的行动设计。
- `right-it-diagnosis`: 用于区分失败类型。
